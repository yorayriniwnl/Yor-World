# yorayriniwnl.in

This folder contains the local source project for YOR WORLD at `https://yorayriniwnl.in`.

## Run locally

Use Node.js `>=24.19.0 <25` and pnpm `9.15.9`. From this folder:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Copy `.env.example` to `.env.local` before configuring local services. Backend-dependent features need the services documented in `.env.example`.
