# Independent audit, correction and Parent acceptance prompts

Use these repeatedly for one exact packet at a time. Parent fills bracketed fields with actual inputs; an unfilled source/hash/ownership field is an incomplete handoff. Independent audit and Parent acceptance are separate actions.

```text

Read AGENTS.md, START_HERE.md, delegation hub, account operating model, FINISH-01 and completion prompt-pack README. Audit only [PACKET ID / REVISION] delivered by [MAKER], on [ACTUAL BASE SOURCE COMMIT/TREE], accepted contracts [REVISION/HASHES], candidate [SOURCE/PATCH/ASSET HASHES], owned paths [EXACT ALLOWLIST]. Read the selected maker prompt, actual specification clauses, original completion audit, maker source/patch/assets/report and actual raw receipts. Open available inputs; report MISSING INPUT/NO FILE ACCESS honestly.

Own only deliveries/completion-audits/[PACKET]/[REVISION]/. Production source, maker delivery, accepted baselines and historical receipts are read-only. Never fix maker code/assets/tests or accept your own output. You may create owned diagnostic programs and run independent checks against an isolated exact candidate. Bind commands/results to source/lock/build/artifact identities and state actual tool/device/service access. Do not treat fixtures, source inspection, forwarded logs, Blender renders or emulation as actual production/physical execution.

Inspect implementation versus each requirement, not just maker PASS counts. Verify substantive block edit/save/reopen/preview/publish/rollback if platform; real animation action/bone/prop outcomes, cancellation/pause/loading/door/clock/project motifs if runtime; main-reference/camera/raw-frame/export/rig/provenance if art; fresh initial mobile geometry and pointer/keyboard accessibility if HUD. Confirm no frozen contract/history drift or out-of-scope edits, no source/evidence mismatch, no stale proof, no weakened assertions/budgets, no private draft/content/secret exposure and no substituted generic reactions. Count accessibility overlap correctly. CandidateX and missing approved credentials remain truthful unavailable states.

Reproduce confirmed failures with minimal targeted diagnostics where tools permit. Report suspected issues as suspected and unrun checks as NOT RUN. For each finding state ID, severity, requirement, exact source line/path, trigger, observed versus required outcome, evidence and assigned maker. Give a closure matrix for original CA findings and new regressions; missing user/provider/device inputs stay open instead of being accepted away.

Return report.md, input/output hashes, actual commands/versions/exit codes, raw diagnostics and PASS/FAIL/NOT RUN evidence table. End with PASS advice or REWORK advice within the inspected scope, confidence/limits and exact maker correction ownership. This is advice, not Parent acceptance. Send defects to the original maker, then use the delta prompt after corrected exact artifacts arrive. Do not quietly substitute an unreviewed revision or make production fixes.
```
