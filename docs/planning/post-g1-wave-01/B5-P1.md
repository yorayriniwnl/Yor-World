## Foundation to implement

1. **Explicit entry and loader ownership.** No world code, GLB, canvas context or audio starts before entry. Production query strings are not automation backdoors. Keep actual loading stages, Cancel and conventional navigation available outside the lazy subtree. Only report byte percentage when totals are real. Required assets are fetched/decoded before the entrance clock begins; secondary assets do not block readiness. Use AbortSignal plus session/transition identity for both success and rejection paths. Dispose partially/late-loaded owned resources.
2. **One renderer session.** Lazy feature-local failure boundary protects HTML even when JavaScript import fails. Renderer creation, first draw, active-frame exceptions, missing/corrupt assets and context loss converge on an idempotent failed-session path. Stop RAF, timers, listeners, mixers, GPU resources and any owned effects before fallback. Show Retry 3D and Continue with portfolio; retry creates one clean session, never revives a failed owner. At 15 seconds with no required-asset progress, expose recovery; at most two automatic request retries with bounded backoff, stopped by cancellation. Do not implement CDN/compression rollout.
3. **One camera director and one common entrance coordinator.** Use existing CameraId and director signatures. Timeline camera ownership is exclusive; camera and character directors never navigate. Camera presets explicitly use runtime meters/Y-up, vertical FOV and real canvas aspect, with collision/visibility checks against the frozen geometry. Provide desktop/mobile safe Home and entrance shots; don't retain a wall-intersecting preset just because it appeared in a proof. Geometry/anchor changes require a separate baseline decision.
4. **Bounded entrance using the accepted five clips.** Implement the existing <=8-second storyboard after readiness, coordinated door/camera/character behavior, safe Home/coding settlement and repeat-entry/replay policy. Keep the accepted rig, transforms, clip names and timing; a lane-private adapter may implement the existing CharacterDirector interface. Initial coding idle must actually be active. No new eight-clip catalog, attention system, object interactions, project effects, dialogs/terminal, likeness or asset re-authoring.
5. **Interruptions and navigation.** Enter→Enter is idempotent. Skip/Escape and direct navigation settle/cancel presentation within the existing <=50 ms target; capture navigation intent before waiting for a slow destination. Next router retains history ownership. Only current work can complete; cancellation prevents late promise/tween/load completions from restarting motion, changing routes or setting stale state. An unmounted component cannot emit a new failure into the active session.
6. **Preferences, visibility and recovery.** Reduced motion on entry and changed while active yields Home/static presentation with at most a 150 ms opacity change, no travel/parallax. Page hide pauses loops, resets time on return and restores a safe state. Storage denied/corrupt/version-mismatched falls back safely. Returning entry avoids replay unless requested. Sound stays off; use no-op audio adapter with zero AudioContext creation in this packet, not a fake working sound system.
7. **Resource ownership and resize.** Handle rapid resize/orientation without a second camera owner, doubled transforms or extra RAF. Dispose owned geometry/materials/textures/skeleton/mixer bindings/listeners on exit or failure, while protecting deliberately shared live assets. Clear cancelled loads and discarded proxy resources. Provide explicit ownership records instead of relying on garbage collection to prove teardown.

Use the accepted G1 dependency/lockfile baseline. Production-plan references to additional state/timeline libraries are not permission to edit shared package/config files independently. Implement behind existing boundaries using the current toolchain, or return a concrete dependency/integration proposal while continuing independent work. Do not copy unstable/new APIs from unrelated docs into a frozen contract.
