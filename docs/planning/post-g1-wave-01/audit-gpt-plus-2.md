## Review return and classification

Return `report.md`, reviewed input/output manifest digest, independent execution ledger/logs and evidence manifest. For each finding include ID, P0/P1/P2/P3, source/symbol, exact reproduction, expected/observed, evidence class/path, minimal correction, required regression, owner and whether it blocks this packet or belongs downstream.

- **P0:** critical security/data-loss or destructive system failure; immediately halt only affected work and escalate appropriately.
- **P1:** required lane behavior, contract/ownership/identity failure, loss of useful semantic content, or unreliable lifecycle/route ownership; blocks acceptance of the affected packet.
- **P2:** meaningful bounded defect/evidence gap; blocks when it violates this packet's required acceptance criteria. A later-product enhancement may be deferred only with an explicit parent disposition.
- **P3:** minor documentation/polish/hygiene with no violated gate invariant; track without silently expanding scope.

Recommend **ACCEPT**, **REWORK**, or **INSUFFICIENT EVIDENCE** separately for A2, B3-P1 and B5-P1. Do not average them into one PASS. Correction returns use a delta closure matrix (FIXED / PARTIALLY FIXED / NOT FIXED / REGRESSED / UNVERIFIED), then check the changed surface for new defects.
