1. Check out repository commit `d88f7e1600087bfc51ee3a04dbb1c8c7978a1f80` separately. Copy `deliveries/G1/source` into a short external scratch directory. Keep original delivery evidence intact.
2. In scratch, use Node 24.19.0 and pnpm 9.15.9. Run `pnpm install --frozen-lockfile`, then `pnpm build`. Run `node node_modules/next/dist/bin/next start --hostname 127.0.0.1 --port 3197`. Next may regenerate its type-only `next-env.d.ts`; this is recorded in run-context.json. No runtime source is modified.
3. Keep a copy of these audit scripts outside the delivery. Set environment variables `G1_AUDIT_APP` to the scratch directory and `G1_OLD_W1` to the pinned checkout's `deliveries/W1/room-blockout.glb` (historical W1-F1, **not** revisions/W1-F1-r2). Optional `G1_AUDIT_URL` defaults to `http://127.0.0.1:3197`.
4. Run `node hostile-browser.cjs`. It uses the Chrome installation through Playwright, writes screenshots/results beside itself, and discovers the world JavaScript chunk from the production build. Use a new output copy for a rerun so these archived receipts remain unchanged. `G1_AUDIT_FILTER` accepts a regex for selected scenario names; `G1_AUDIT_SUFFIX` distinguishes result JSON files. For Edge, set `G1_AUDIT_CHANNEL=msedge`.
5. Run `node real-asset-probe.cjs`. It transpiles the original TypeScript in memory and executes the actual Three scene integrator/character director with actual GLBs. It stubs image decoding for graph-only checks and injects only the loader/renderer adapters for the stale-error-callback case. Browser tests decode and render the real assets. The intentionally delayed rejection writes an expected initialization-error diagnostic; `additional-execution.json` records process exit 0.
6. Run `python verify-identities.py` from a fresh copy of this package in the matching checkout to reproduce Git/archive/input binding. Its historical archive comparison excludes line-ending-only changes from substantive source differences.

The archived Chrome batches completed 22 unique cases: initial 15 completed cases plus the corrected context-loss case and six added cases. The initial batch also retains one harness-only context-restoration error. Seven selected cases were corroborated in Edge. Existing maker happy-path/unit suites were inspected rather than rerun; the user specifically requested hostile cross-system testing.

Faults injected: delayed/404/truncated GLB responses; blocked/delayed actual world JavaScript chunk; delayed actual destination RSC response; browser WEBGL_lose_context; getContext returning null; a bounded draw-call exception; changed browser reduced-motion media query; synthetic hidden/pagehide events; historical asset bytes served with stale-cache headers. Reports distinguish these from production defects and from untested physical-device behavior.

WebGL instrumentation holds references to contexts/resources to count create/delete calls. Therefore counts prove missing deterministic release; they do not measure physical GPU heap retention after garbage collection. Browser lifecycle instrumentation also tracks framework listeners/timers, so the audit compares world-owned additions against the same-page baseline instead of demanding that the entire browser have zero listeners.
