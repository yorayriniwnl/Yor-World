# P30 setup corrections and preserved failures

P30 source and browser execution have not started. The entries below describe setup-only failures and corrections preserved under `attempt-01`; they do not count as source build or capture results.

The first controlled-runner probe invocation exposed a PATH/launcher issue and did not qualify. Its files remain in `runner-probes/`. The corrected runner is `runner/run-child.ps1`; its one exit-0/exit-23 probe pair is preserved in `runner-probes-attempt-02/` and passes with numeric child exits and byte-matching stdout/stderr.

The first accepted-source install ran from `D:\p30-source-500` without an explicit D: pnpm store. It was interrupted before a child receipt or numeric exit existed and is classified `INCOMPLETE_NOT_PASS` in `commands/accepted-root-500/install.interrupted.receipt.json`. That receipt retains the original request and stream sizes/hashes, including stdout 4,096 bytes / SHA-256 `48abc7a1a15400860953f294f3dc43db3206e3d6ce06f281a539f984adc9ff32`, but the original raw request/stdout/stderr files were overwritten when the completed attempt reused those paths. Their original bytes are not preserved, and this report does not claim otherwise. The interruption left an ignored partial `app/node_modules` tree (16,288 files / 250,671,888 bytes). The temporary P28 overlay was archived as `source-worktrees/accepted-root-500-interrupted-install-overlay.patch`; tracked source was restored to accepted commit 500d, while the ignored partial dependency directory was left untouched.

An overbroad process prelaunch guard matched the calling PowerShell itself. The preserved `commands/accepted-root-500-install-launch-preflight-01.json` labels this `NOT_LAUNCHED/SELF_MATCH_FALSE_POSITIVE`; no install child or install receipt was created by that guard. The later clean accepted install used a fresh worktree and explicit `--store-dir D:\pnpm-store-p30`.

An early overlay identity generator invocation used an invalid `git diff --output` argument position and emitted its patch to the command output rather than the intended file. The corrected 38,653-byte patch was saved and hashed before the old worktree was restored. A first current-source binding JSON generator also failed at serialization because its ordered dictionary used numeric port keys; it created no manifest. `source-worktrees/current-binding-generator-failure-01.md` preserves that packaging error, and the corrected manifest uses string keys.

The first derived resolver-matrix generator used a nonexistent nested donor path and produced a matrix with a null donor record; its file is preserved as `runtime-resolver-corrected-matrix.attempt-01-invalid.json` with the generation failure note beside it. The third generator uses the existing flat donor resolver path and emits `runtime-resolver-matrix-attempt-03.json`; both active sources show all six checks passing.
