PRE-G7-29 resolver-probe attempt 01 failed due to the probe wrapper, before any install, preflight, build, or browser action.

The wrapper passed JavaScript expressions containing embedded quote characters through Windows PowerShell native argument conversion. Node v24.19.0 therefore received `process.execPath + | + process.version` and returned `SyntaxError: Unexpected token '|'` for both the direct expression and the `pnpm exec node` expression, on both source worktrees. The wrapper then threw `GetFullPath` path-format errors before writing resolver receipts. This was a wrapper/argument-construction failure, not evidence of a Node resolver mismatch. The captured command output showed Node.js v24.19.0. The incomplete attempt is preserved; only the corrected resolver probe is authorized before installs.
