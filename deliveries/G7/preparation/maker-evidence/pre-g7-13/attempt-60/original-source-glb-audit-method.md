# Original source and GLB audit method

`original-source-glb-audit.json` is an exact copy of the pre-edit inventory at `deliveries/G7/preparation/maker-evidence/pre-g7-13/pre-edit-source-glb-audit.json`. Its integrity is recorded in `../final-checksums.json`. It describes the pre-edit source base `133529868c8c7279831cbbffe35ab23178012b8c` and app tree `06f2b4ad62f8022bc4f2d410d67ffa197316e6ab`; it is not a claim that the final runtime values are the original values.

The GLB inspection reads `app/public/models/production-room-full.glb` as bytes, hashes the complete file with SHA-256, validates the `glTF` magic, reads the JSON chunk length from the GLB header, parses the JSON chunk, then inspects `nodes`, `meshes`, primitive material indices, accessors, and authored light declarations. Mesh material users are derived by mapping primitive material indices to node mesh references. The source inventory records the named light types, authored positions and glTF intensities, target material PBR/emissive factors and strengths, shared node users, named-node transforms and mesh bounds. The focused material parser is archived as `inspect-original-glb.mjs`; from the repository root it can reproduce the material/shared-user subset to `attempt-60/reproduced-glb-material-baseline.json` without writing to the application or historical attempts.

The unchanged GLB is 861,364 bytes with SHA-256 `3a02647d24e474c8a2579b0d277cf02a7841212e961c1554f67b6e032e40a307` and 222 glTF nodes. The source code color-management check confirmed `THREE.ACESFilmicToneMapping`, exposure `1.15`, and no app-level `outputColorSpace` override. These are source facts; the browser screenshots use the separately logged WebGL/Chromium environment. Final in-memory named light/material values are captured in the desktop/mobile `browser-environment` measurement JSONs and are not written to the GLB.
